## Why this portfolio

This site is a working example of frontend **SEO** and **SSG**, not just a brochure.

Enterprise Angular apps are often client-rendered. Search engines and social crawlers then see a thin shell instead of real titles, descriptions, and content. This portfolio is an Angular 22 SSR/SSG app: routes are prerendered, metadata and canonical URLs are absolute, and the HTML that ships is the page — crawlable, shareable, and fast on first paint.

That is the same approach I use when an enterprise front end has to rank, preview correctly, and still stay a maintainable Angular codebase.
